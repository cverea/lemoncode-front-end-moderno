# lemoncode-front-end-moderno
Proyecto de fin de curso del máster en front end moderno de LemonCode

## App

React + TypeScript + Tailwind + TanStack Router, with json-server as mock backend (`app/db.json`).

```
cd app
npm install
npm start   # vite (5173) + json-server (3001, proxied at /api)
```
